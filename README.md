# Citadel Archive

### Version 1.0 — By Arbaaz Sumar

A Python command-line application for managing character records from Westeros and the Free Cities.

This is my first deep dive into Python and the first project in my journey toward becoming an AI developer.

## Features

- View all character records
- Search for a character by name
- Add new characters
- Prevent duplicate records
- Remove existing characters
- Save records to JSON
- Load saved records automatically
- Handle missing or damaged archive files

## Concepts Practised

- Python functions
- Lists and dictionaries
- Loops and conditional logic
- Input validation
- JSON file handling
- Exception handling
- Refactoring and reusable helper functions

## Running the Application

Make sure Python 3 is installed, then clone the repository and run:

```bash
python citadel.py
```

The application will load the existing archive and display an interactive menu.
